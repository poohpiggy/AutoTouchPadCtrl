# AutoTouchPadCtrl

专为使用第三方驱动的 Windows 版 Chromebook (Lenovo Flex 5 Chromebook/Google Akemi) 打造的轻量 PowerShell 脚本。可在平板模式下自动禁用触控板，解决误触问题，后台静默低耗运行，支持开机自启与一键卸载。

A lightweight PowerShell script for Chromebook running Windows with custom third-party drivers. It auto-disables touchpad in Tablet Mode to fix accidental touches, runs silently with low resource usage, supports auto startup and one-click uninstall.
