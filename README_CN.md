# AutoTouchPadCtrl

Chromebook 第三方驱动专用 \| 平板模式自动管控触控板

适配刷入 Windows 系统、使用第三方移植驱动的 Chromebook 翻转设备 (Lenovo Flex 5 Chromebook/Google Akemi) 。这类设备缺少完整官方适配，驱动本身没有平板模式联动逻辑，翻转成平板形态后触控板不会自动关闭，手写、触屏操作时很容易发生误触、光标乱窜。

自用调试编写此脚本，切换平板模式自动禁用触控板，切回常规桌面模式即可恢复使用，有效解决日常使用痛点。

## 运行原理

实时读取注册表内平板模式状态
`HKCU:\\Software\\Microsoft\\Windows\\CurrentVersion\\ImmersiveShell\\TabletMode`

- 数值为 1：开启平板模式，自动关闭触控板

- 数值为 0：关闭平板模式，自动启用触控板

脚本记录设备上一次运行状态，仅状态变动时调整触控板，减少无效运行。

## 适配设备

- 搭载 Windows10、Windows11 系统的 Chromebook 设备

- 仅适用于第三方移植驱动机型，官方原装驱动无需使用

- 默认适配 ELAN 触控板，设备 ID：`ACPI\\ELAN0000\\0`

2. 右键进入属性，切换至详细信息页面

3. 复制设备实例路径，替换脚本内默认 ID 即可
